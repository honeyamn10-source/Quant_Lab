The Falsification Battery

Six independent tests. A strategy must pass all to be considered robust. No single metric tells the whole story.

Probabilistic Sharpe Ratio (PSR)

Bailey & López de Prado (2014). Adjusts Sharpe for non-normal returns, sample size, and skewness/kurtosis. PSR > 0.95 = statistically significant.

Deflated Sharpe Ratio

Bailey & López de Prado (2014). Corrects for multiple testing (data snooping). Accounts for number of trials, correlation between strategies.

Probability of Backtest Overfitting (PBO)

Bailey et al. (2016). Combinatorially exact: what fraction of permutations produce better in-sample than out-of-sample? PBO < 0.05 = robust.

Purged Cross-Validation

López de Prado (2018). Embargoes between train/test folds to prevent leakage from autocorrelation. Configurable embargo percentage.

Walk-Forward Analysis

Expanding/rolling windows. Train on T, test on T+1. Reports hit rate, OOS Sharpe, max DD per window. Expanding vs anchored.

Monte Carlo Simulation

Block bootstrap (stationary + circular). 10,000+ paths. Confidence intervals for Sharpe, DD, hit rate. Non-parametric, distribution-free.

Data Pipeline

Clean data in. Reliable results out.

data_pipeline.py
from quantlab.data import PriceLoader, ReturnsCalculator, Universe # Load from multiple sources loader = PriceLoader( sources=["yahoo", "polygon", "custom_csv"], cache_dir=".cache" ) # Define universe universe = Universe("SP500", lookback="5Y") # Load & align prices = loader.load(universe.tickers, start="2019-01-01") prices = prices.align(method="forward").clean() # Calculate returns returns = ReturnsCalculator().log_returns(prices) # Corporate actions handled returns = returns.adjust_splits().adjust_dividends() # Save for falsification returns.to_csv("returns.csv")
