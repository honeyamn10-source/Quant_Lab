03 / Run it yourself

Start from the source.

Python 3.12 or later. Optional extras add web, ML, tracking and storage integrations.

Clone the repository, then use the commands below. Review the README before connecting external services.

SOURCE CHECKOUT
git clone https://github.com/honeyamn10-source/Quant_Lab.git
cd Quant_Lab
python -m pip install -e ".[dev]"
quantlab data generate-synthetic --out datasets/ --seed 7 --symbols SYN
quantlab run-experiment examples/strategies/sma_crossover.yaml
04 / Know the scope

Clear expectations.

Research software. Statistical checks expose some failure modes; they do not guarantee unbiased models or profitable strategies. Read the methodology before interpreting results.

See GitHub Actions for commit-specific test and build results.
